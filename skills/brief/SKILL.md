# brief

흰 배경·검은 제목·장식 없는 학술 톤의 16:9 슬라이드를 HTML 로 써서 Chrome 으로 PDF 를 뽑는다. 큼직한 시각화가 중심이고 글은 최소한이다.

## 순서
1. **범위 확정**: 요청이 가리키는 주제만 다룬다. 요청 밖 내용(변경 이력·로드맵 등)은 넣지 않는다. 주제를 못 정하겠으면 그때만 묻는다.
2. **소스 읽기**: 주제에 필요한 코드·문서만 읽는다.
3. **틀 보고**: 만들기 전에 채팅에 전체 틀을 적는다 — 전달할 핵심 한 줄 + 슬라이드별 `제목 · 들어갈 내용 · 시각화 종류`. 표지·목차·장수 제한은 없다. 적은 뒤 바로 이어서 만든다.
4. **작성**: `template.html` 복사해 틀대로 슬라이드를 채운다. 중간 파일(html·svg·차트 json·미리보기 png)은 모두 `/tmp` 쪽 작업 폴더(세션 scratchpad 가 있으면 거기)에 둔다. pwd 에 흩뿌리지 않는다.
5. **빌드**: 사용자의 pwd 에서 `bash <skill>/scripts/build.sh /tmp쪽/deck.html` → 작업 폴더에 `deck.pdf` + `deck-preview-N.png`, 통과하면 `deck.pdf` 가 pwd 로 복사된다(최종 산출물은 이 PDF 하나). 넘침(`data-overflow`)·쪽수 불일치면 실패하니 줄이거나 쪼갠다.
6. **보고**: pwd 로 옮겨진 PDF 경로(`final:` 줄)와 함께 채팅에 알린다. 측정 조건·출처 한계·주의점은 슬라이드가 아니라 채팅에만 쓴다. 그림 평가는 사용자가 한다.

## 글
- 제목: 번호·주제 명사구
- 본문 형식은 자유 — 짧은 줄, 줄글, 목록 아무거나. 목록은 `·` 로 시작한다 (`-` 금지). `→`·`⇒` 로 시작하는 줄에는 `·` 를 붙이지 않는다(자동 제거되지만 처음부터 `<p>` 로 쓴다)
- 문장 안에서도 줄글로 풀지 않고 기호로 압축한다: `A → B`, `⇒ 결과`, `·` 구분, `≥`, `×`
- 수치는 핵심만 간단히, 자세한 수치는 차트·표·SVG 로
- 줄은 짧게. `word-break:keep-all` 이 단어 중간 줄바꿈을 막지만 어색하게 꺾이면 문구를 줄이거나 글씨·그림 비율을 조정한다

## 레이아웃
좌 텍스트/우 시각화(`split`, 5:7 은 `wide-r`) · 꽉 찬 시각화(`full`) · 변경 전후 블록 · 흐름도. 같은 레이아웃을 연속 3장 넘게 쓰지 않는다. 한 장에 안 들어가면 쪼갠다.

## 시각화
- 색은 `:root` 의 `--c1..c6` 변수만. 차트·흐름도·diff 가 같은 팔레트를 공유한다. 리터럴 색 금지
- 차트: `python3 scripts/chart.py spec.json` → SVG. spec: `{"type":"bar|line","title","unit","labels":[..],"series":[{"name","values":[..]}]}`. 단일 시리즈 막대는 항목마다 다른 색(경향이 잘 보이게), 시리즈 단위 색이 필요하면 `"color_by":"series"`. 막대는 0 기준선, 선은 `ymin`/`ymax`. 좌표는 값에서 계산되므로 수치를 손으로 옮기지 않는다. 막대 6개·선 8점 넘으면 쪼갠다
- 변경 전후: `git diff -U0 ... | python3 scripts/diff.py` — 파일명·헤더 없이 빨강(-)/초록(+) 블록만, hunk 사이는 한 줄 띄움. 핵심 줄만 남긴다
- 이미지: `python3 scripts/imgs.py COLS 경로|캡션 ...` → 그리드 HTML(1장이면 COLS=1). 경로는 덱 html 기준. 비율이 달라도 잘리지 않고 캡션이 이미지에 붙는다. 6장 넘으면 쪼갠다
- 표: `python3 scripts/table.py < data.csv` (첫 줄=헤더). 숫자 칸 우측 정렬, `**굵게**`로 채택값 강조. 행이 많으면 `style="--fs:20px"`를 감싸는 div 에 주거나 쪼갠다
- 이미지+표·그리드+표 는 `split` 으로 각각 `<div>` 에 넣어 조합한다
- 흐름도: 템플릿처럼 직접 SVG. 박스·화살표·`stroke` 만, 그라데이션·그림자 금지

## 금지
제목 밑줄·색 띠·그림자·그라데이션·이모지, 슬라이드에 발표자용 설명·출처 주의 문구 쓰기.
